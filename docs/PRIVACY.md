# 隐私政策 / Privacy Policy

**正文只有一份，而且它是发布出去的那一份：**

- 中文 · **<https://briffy.cc/privacy>**
- English · **<https://briffy.cc/en/privacy>**
- 源文件 · [site/privacy.html](../site/privacy.html)（双语一份，`npm run site` 切成上面两页）

## 为什么不在这里再写一遍

隐私政策是对外的承诺，法律上生效的是**用户能打开的那个网址**。仓库里再放一份 Markdown，两份迟早不一样——
而不一样的那一天，写在网上的那份说的是一件事、写在仓库里的说的是另一件，两份都不再可信。

所以这里只留指路。要改政策就改 [site/privacy.html](../site/privacy.html)，然后 `npm run deploy`。

## 它覆盖什么

一页里同时讲桌面端和浏览器扩展，因为它同时是两处的必填项：

| 用在哪 | 要求 |
| --- | --- |
| Chrome 应用商店的 Privacy practices | 必填一个公网隐私政策 URL，见 [chrome-web-store.md](chrome-web-store.md) §3 |
| Mac App Store 的 App Privacy | 同上，见 [app-store/app-privacy.md](app-store/app-privacy.md) §5 |
| 官网页脚 | 每一页都链到它 |

**改了政策，这三处的申报表要跟着核一遍。** 尤其是 [app-store/app-privacy.md](app-store/app-privacy.md)
那张逐项表和 [chrome-web-store.md](chrome-web-store.md) §3 那张——申报和政策说的必须是同一件事。
