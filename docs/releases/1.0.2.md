## briffy 1.0.2

### Permissions finally explain themselves

- **When a macOS permission blocks a feature, briffy now opens a guide page** naming the one permission missing — Screen Recording, Microphone, or Accessibility — with a button that lands on that exact System Settings pane and a button to restart briffy afterward. Before, the only signal was a nine-second line on the paperclip, which is designed never to appear in a screenshot; people pressed the screenshot key for days thinking briffy was broken.
- **It spells out the trap that cost the most time:** after an update, the Screen Recording toggle can look on while the grant no longer applies. The page says: turn it off and on again, then restart.
- **Screenshots no longer silently save a wallpaper.** Without Screen Recording, macOS returns an image with every window wiped out; briffy used to file that as a record. Now it refuses to capture and shows the guide instead.
- **Accessibility is checked for the first time.** Reading a window's own text, window titles, and long shots depend on it; when it's missing you're told, at most once an hour, instead of getting silently worse OCR.

### The paperclip

- **It no longer appears over full-screen apps.** It also no longer follows you across desktops — the same flag did both, and a clean full-screen view won.

### Updates

- **briffy now checks for new versions** (Settings › Updates, on by default) and tells you one exists with its size. It never downloads on its own — you decide.

### Saving web pages (extension 0.1.3)

- **Bookmarking a page saves the whole page:** the full text *with comments* — a 1,723-comment thread went from 104 characters captured to 456,827 — and the page's images and video as files rather than links.
- Comments are collected on X, Reddit, Xiaohongshu, Zhihu and Bilibili too; the site-specific path used to skip them entirely.

### Asking from Claude Code, Codex, or any MCP client

- **MCP search now uses the same retrieval as the app.** Ask in plain words — "the start and end addresses" finds the record with the postcode even though it never contains the word "address". (The five kinds — clipboard / screenshots / saved / files / recordings — were already there in 1.0.1; this release makes the search itself as good.)
