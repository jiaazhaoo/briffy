briffy 浏览器扩展

装上它以后，在任何网页按 Alt+Shift+D（或点扩展图标），就能把这一页的图片、视频、音频挑出来存进 briffy。

等待扩展连接…

  1. 打开扩展管理页

    浏览器不允许别的程序直接跳转到这个地址，请复制后粘贴到地址栏：

    chrome://extensions/

  2. 打开右上角的「开发者模式」

    开关在扩展管理页的右上角。

  3. 点「加载已解压的扩展程序」，选择这个文件夹

  4. 完成

    装好后这个页面会自己变成绿色。之后在任意网页按 Alt+Shift+D 即可。

如果你用的是 Edge，地址换成 edge://extensions；Brave 是 brave://extensions。
